# Agent Space — 팀 에이전트 스페이스 프로토타입

빌드 없이 `index.html`을 브라우저로 열면 바로 동작하는 클릭 가능한 프로토타입입니다.
(정적 파일 3개 + 더미 데이터. 프레임워크·번들러 없음. 기본 테마는 라이트)

```bash
open index.html          # 또는
python3 -m http.server 8080
```

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 셸 (root div + 스크립트 로드) |
| `styles.css` | 디자인 토큰 · 컴포넌트 스타일 (라이트/다크) |
| `data.js` | 워크스페이스 · 리소스 · 마켓플레이스 더미 데이터 |
| `app.js` | 해시 라우팅, 상태, 렌더 함수, 이벤트 위임 |

## 헤더 규칙

**로그인 전** — 좌측 로고, **가운데에 아이콘 + 문구 주요 메뉴**(홈 · 다운로드 · 사용 케이스 · 마켓플레이스), 우측에 테마 토글과 로그인/시작 버튼.

**로그인 후** — 우측에 같은 메뉴를 **아이콘만으로** 배치(홈 · 다운로드 · 사용 케이스 · 마켓플레이스) + 테마 + 계정. 좌측은 화면 성격에 따라 갈립니다.

**전역 화면 vs 스페이스 화면** — 마켓플레이스 · 소개 · 다운로드 · 사용 케이스는 **팀 레벨과 무관한 전역 화면**입니다.

| | 좌측 | 스페이스 진입 |
| --- | --- | --- |
| 전역 화면 | 브랜드 + `전역` 배지 (스위처 없음) | 우측 `내 스페이스 ▾` 메뉴 |
| 스페이스 화면 | 워크스페이스 스위처 (로고 마크와 중복되지 않게 제거) | — |

어느 쪽이든 스페이스를 고르면 **바로 그 스페이스의 홈**으로 이동합니다.

## 정보 구조

### 1. 로그인 전 — 마케팅

| 라우트 | 화면 |
| --- | --- |
| `#/intro` | 소개 (히어로 · 4가지 자산 타입 · 개인/조직 모드 비교 · CTA) |
| `#/download` | 다운로드 (macOS/Windows/Linux/웹 · CLI 설치 · 요구사항) |
| `#/usecases` | 사용 케이스 (팀별 6가지 시나리오 + 사용 자산 조합) |
| `#/marketplace` | 마켓플레이스 — 로그인 전에는 둘러보기만, 가져오기는 로그인 유도 |

`#/download`와 `#/usecases`는 로그인 후에도 앱 상단바 아래에서 그대로 열립니다.

### 2. 로그인 후 — 스페이스

상단바 워크스페이스 스위처로 모드를 바꿉니다.

- **개인 모드** (`개인 스페이스`) — 나만 보이는 공간
- **조직 모드** — `Acme Corp`(전사, 관리자) · `프로덕트 디자인팀`(일반 멤버) · `그로스 마케팅실`(관리자)
  - 역할에 따라 마켓플레이스 설치가 즉시 반영되거나 승인 요청으로 바뀝니다

사이드바:

```
홈       #/home        요약 · 최근 활동 · 빠른 시작 · 최근 자산
스킬     #/skills      반복 작업을 절차로 정리
에이전트  #/agents      스킬+플러그인을 조합한 실행 주체
아티팩트  #/artifacts   에이전트가 산출한 문서·대시보드·페이지
플러그인  #/plugins     외부 도구 연결
── 관측 ──
실행 로그 #/logs        시각·대상·실행자·상태·소요·토큰 (성공/경고/실패 필터)
사용 분석 #/analytics   일별 실행량 · 성공률 · 가장 많이 쓰인 자산
비용     #/costs       월 누적·예상치 · 항목별 비용
── 조직 관리 ──
멤버     #/members     조직 모드에서만 노출
설정     #/settings    모드에 따라 항목이 달라짐
```

모드에 따라 달라지는 것:

| | 개인 모드 | 조직 모드 |
| --- | --- | --- |
| 사이드바 | 멤버 메뉴 없음 | 멤버 메뉴 노출 |
| 홈 사이드 카드 | 마켓플레이스 추천 | 승인 대기 목록 |
| 리소스 카드 배지 | 상태만 | 상태 + 공개 범위(조직 공개/제한 공유/비공개) |
| 목록 필터 | 전체 · 내가 만든 | + 조직 공개 · 검토 대기 |
| 설정 | 개인 정책 | 조직 정책 (설치 승인, 외부 공유, 감사 로그) |

### 3. 제작한 것 / 가져온 것 구분

스킬·에이전트·아티팩트·플러그인 목록은 두 갈래로 나뉘어 표시됩니다.

- **직접 만든 …** — 이 스페이스에서 작성. 카드 하단에 작성자 표시
- **마켓에서 가져온 …** — 마켓플레이스에서 선택해 설치. `가져옴` 배지 + `퍼블리셔 제공` 표기

툴바 우측에 `직접 만듦 n · 가져옴 n` 요약이 붙고, 가져온 항목이 없으면 그 자리에 "둘러보기" 안내가 남습니다.

### 4. 마켓플레이스 (별개 영역)

`#/marketplace` — 사이드바 없이 전체 폭을 쓰는 독립 화면. 좌측에 필터 레일이 붙습니다.

- 상단 탭: **전체 / 스킬 / 에이전트 / 플러그인**
- **업무 영역**: 전사 공통 · 개발·IT · 마케팅 · 영업 · 재무·회계 · 인사 · 고객지원 · 데이터 · 디자인 · 법무·총무
- **연동 시스템**: 그룹웨어·전자결재 · 사내 위키 · Jira · GitHub Enterprise · Slack · Figma · SAP ERP · 인사시스템 · CRM · 사내 DW · 마케팅 자동화 · Datadog
- 두 축은 교차 적용되며, 각 항목의 건수는 나머지 조건을 반영해 계산됩니다
- **가져오기 → 대상 스페이스 선택 모달**
  - 개인 스페이스 / 조직(관리자) → 즉시 설치
  - 조직(일반 멤버) → 관리자 승인 요청(`검토 대기` 상태로 추가)
- 설치하면 대상 스페이스의 목록에 실제로 반영되어 "가져온" 섹션에 나타납니다

## 구현 메모

- 상태는 `app.js`의 `state` 객체 하나. 변경 시 `render()`로 전체 리렌더 (입력 포커스는 복원 처리).
- 이벤트는 `document` 레벨 위임 + `data-action` 속성.
- 다크/라이트는 `:root` / `[data-theme="dark"]` CSS 변수, 헤더 토글로 전환. 기본값은 라이트.
- 실행 로그·분석 수치는 워크스페이스의 실제 자산에서 결정적으로 생성합니다(랜덤 없음).
- 연결되지 않은 버튼은 `data-action="noop"` → "프로토타입입니다" 토스트.
